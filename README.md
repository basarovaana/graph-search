# Graph Search Algorithms

Реализация и сравнение алгоритмов поиска пути в графе с визуализацией пошагового выполнения.

## Алгоритмы

- **BFS** (поиск в ширину)
- **DFS** (поиск в глубину)
- **Dijkstra** (кратчайший путь во взвешенном графе)
- **Bellman-Ford** (кратчайший путь, поддерживает отрицательные веса)
- **A\*** (эвристический поиск)

## Установка

```bash
pip install networkx matplotlib
```

## Использование

Запуск бенчмарка и генерация данных для визуализации:

```bash
python main.py
```

Запуск интерактивного визуализатора:

```bash
python visualizer.py
```

В визуализаторе можно выбирать алгоритм, тип графа (Best / Worst / Random) и размер, а также листать шаги выполнения кнопками **Prev** / **Next**.

## Бенчмарк

Бенчмарк тестирует каждый алгоритм на трёх типах графов:

| Тип | Описание |
|-----|----------|
| Best | Линейная цепочка — минимум рёбер |
| Worst | Полный ориентированный граф |
| Random | Случайный граф с плотностью ~30% |

Размеры графов: 10, 50, 100, 200 вершин. Для каждой конфигурации выполняется 10 замеров, вычисляется среднее время и доверительный интервал (95%).
